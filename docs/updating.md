# Обновление установленной версии

Первый поддерживаемый вариант — установленное приложение Windows x64. Строка версии находится над настройками. При запуске и каждые шесть часов приложение читает последний стабильный релиз фиксированного репозитория `MikkiMays/ModernStreamingSystem.Windows`. До нажатия «Обновить» пакет не скачивается.

Принимается только новая версия `X.Y.Z`, не draft/prerelease, с точным именем `Cord-Setup-X.Y.Z-x64.exe` и SHA-256 `digest` GitHub. Загрузка и перенаправления допускают только HTTPS и разрешённые хосты GitHub. Размер и хеш проверяются до перемещения `.partial` в готовый файл. Неудачная загрузка оставляет установленную версию и даёт повторить попытку.

Во время встречи скачанный пакет ждёт. После её завершения помощник читает UTF-8 JSON-план, проверяет SHA-256 средствами .NET и создаёт файл готовности. Cord закрывается только после этой готовности и повторной проверки отсутствия звонка. Помощник ждёт завершения процесса, повторно проверяет пакет и запускает существующий Inno Setup:

`/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /NOCANCEL /CLOSEAPPLICATIONS /DIR="текущий каталог" /LOG="журнал"`

AppId остаётся прежним; профиль WebView2, избранное и настройки расположены вне заменяемых файлов. Приложение запускается снова по окончании. В каталоге профиля `updates` остаются `installer.log` и результат применения. Ошибка результата показывается при следующем запуске.

[Параметры Inno Setup](https://jrsoftware.org/ishelp/topic_setupcmdline.htm). 0.3.0 не содержит загрузчика: нужен один переходный запуск нового установщика. Portable ZIP не определяется как установленная версия и автоматически не обновляется.

`ReleaseTests` проверяет версии, архитектуру, origin, HTTPS, размер и хеш. `scripts/test-installer.ps1` запускает настоящий установщик и тот же помощник, который включён в приложение: каталог с пробелом/кириллицей, ожидание живого родителя, повреждённый пакет, повторное применение, профиль и запись удаления. `--verify-service` дополнительно проверяет возврат размеров после нативного fullscreen и сохранение WebView2. Физический звонок, DPI, обрыв сети/занятые файлы и переход между двумя опубликованными релизами требуют отдельной приёмки.
