Cord 0.3.0 adds a configurable global microphone shortcut that works while a call is active, including when another application has focus. The default is Ctrl+Shift+M. Settings now include an editable default display name and no longer contain a separate device-access request button.

The shared meeting interface adds reliable admission after host approval, microphone processing and private device checks, per-listener volume, favorite-room autojoin, and room integrations for music, Yandex Music and @cord_meet_bot. Autojoin starts with the microphone on and camera off. Yandex uses one account per room; participants allowed integrations can connect or replace it by agreement.

Download `Cord-Setup-0.3.0-x64.exe` and run it. The installer includes .NET, Windows App SDK and the offline WebView2 Runtime package, and connects to https://meet.nikg.tech. Existing profiles and settings are retained. Windows x64, Windows 10 build 19041 or later. The installer is not yet signed with a publisher certificate.

Publication requires Windows tests, WinUI resource launch, a native connection to the deployed service, and installation/upgrade/uninstallation checks. SHA-256 files accompany the installer and portable ZIP.
