# Cord 0.6.0

## Сначала сервер, потом встречи

Cord теперь открывается на **экране подключения**, а не на списке комнат. Пока сервер не
ответил, ничего о встречах не показывается: избранное принадлежит серверу, и показывать
комнаты одного сервера, будучи подключённым к другому, было бы неправдой.

На экране — сохранённые серверы с синим плюсом, шестерёнкой у каждой строки и полем пароля.
Добавить сервер можно, не дожидаясь, пока он поднимется: **«Проверить подключение»** —
отдельная маленькая кнопка, которая отвечает на вопрос и оставляет вас на месте. Внизу слева
загорается зелёное «Подключено!» либо красное «Не подключено» со стрелочкой, под которой
написано, что именно не так: пароль не тот, адрес не тот, сертификат не принят, сервер ещё
запускается.

Сервер с **автоподключением** открывается сразу, без вопросов, — так же, как автоподключение
работает во встречах. Выключите галочку, если хотите выбирать каждый раз.

## Пароль на сервер

Сервер Cord теперь может быть закрыт паролем (`ACCESS_PASSWORD` на стороне сервера, по
умолчанию пусто). Приложение спрашивает его один раз и, если вы согласились, запоминает —
зашифрованным средствами Windows для вашей учётной записи, отдельно для каждого сервера.
В `settings.json` пароль не попадает: этот файл переносят между машинами.

Страница внутри приложения пароля не видит никогда. Ей передаётся только короткоживущий
пропуск, а когда он истекает — приложение молча берёт новый. Встречу это не прерывает.

## Настройки разобраны

«Звуки уведомлений» и «Показывать задержку / PING» больше не лежат под полем адреса и строкой
ошибки, к которым они не относятся. Диалог разделён на «Профиль», «Звук», «Подключение» и
«Оформление», а выбор сервера уехал в свой собственный экран.

Блок профиля внизу боковой панели стал кнопкой: там, где имя и сервер, теперь и открываются
их настройки. Рядом — кнопка серверов.

## Что изменилось на стороне сервера

Интерфейс встречи загружается с сервера, поэтому следующее приезжает без переустановки:
**звуки на вход и выход каждого участника**, на запрос подключения и на ваш собственный вход
и выход. При закрытии приложения с открытой встречей сначала звучит выход, потом закрывается
окно.

## Установка

Скачайте `Cord-Setup-0.6.0-x64.exe` и запустите. Установка для текущего пользователя, без прав
администратора. Сохранённые серверы, имя и настройки переносятся; сервер, на котором вы были,
открывается автоматически. Windows x64, минимум Windows 10 build 19041. Установщик пока не
подписан сертификатом издателя.
