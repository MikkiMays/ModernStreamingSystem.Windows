# Cord 1.0.7

## Высокий приоритет в Windows

Cord теперь работает с приоритетом «Высокий» всё время, пока он запущен, а не только во встрече, и
Windows не переводит его в режим эффективности: голос и звук показа не уступают процессор игре или тяжёлой
программе рядом. В диспетчере задач у Cord на вкладке «Подробности» — приоритет «Высокий».

## Установка

Если Cord уже стоит, обновление придёт само при запуске. Иначе — скачайте установщик со страницы
`/download`.
