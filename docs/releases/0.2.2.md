Cord 0.2.2 connects a new installation to https://meet.nikg.tech automatically. The Windows app and browser use the same rooms, calls, screen sharing, chat and file service. Existing profiles keep their saved server address and permissions.

Download `Cord-Setup-0.2.2-x64.exe` and run it. This single installer includes .NET, Windows App SDK and the offline WebView2 Runtime package; no local server is required. Windows x64, Windows 10 build 19041 or later. The installer is not yet signed with a publisher certificate.

The release workflow requires the Windows tests, WinUI resource launch and installation/upgrade/uninstallation checks to succeed before publication. SHA-256 files accompany the installer and portable ZIP.
