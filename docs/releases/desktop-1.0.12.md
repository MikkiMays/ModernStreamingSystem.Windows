# Cord 1.0.12

## Оверлей в игре

- В виджете «Говорящие» имена у всех на одной тёмной плашке, а того, кто говорит, выделяет кольцо вокруг
  аватара — как в образце в настройках «Оверлей». Раньше у говорящего плашка имени становилась зелёной,
  и образец в настройках с игрой не совпадал.

## Установка

Если Cord уже стоит, обновление придёт само при запуске. Иначе — скачайте установщик со страницы
`/download`.
