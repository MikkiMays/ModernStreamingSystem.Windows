# Cord 0.7.4

## Избранные комнаты в удобном порядке

Комнаты в левой панели можно перетаскивать выше и ниже. Тот же порядок сохраняется на
сервере и отображается в веб-клиенте. Для управления с клавиатуры в контекстном меню
комнаты доступны команды «Выше» и «Ниже».

После перетаскивания комната не открывается случайным нажатием. Если сервер не смог
сохранить порядок, приложение возвращает прежний список и показывает причину.
Серверы без поддержки сортировки продолжают открывать избранные комнаты.

Исправлена загрузка избранного: приложение больше не отклоняет список, в котором
больше пяти комнат.

## Обновлённый интерфейс встречи

На обновлённом сервере доступны изменения общего веб-интерфейса:

- Копирование сообщений, более различимые сообщения и актуальное состояние интеграций.
- Согласованные кнопки полноэкранного режима.
- Обновлённые столы покера и дурака, история партий, анимации действий и реакции.
- Дополнительный способ воспроизведения YouTube с выбором доступного HD-качества.

Эти изменения загружаются с сервера. Максимальное качество видео зависит от источника
и поддерживаемых устройством кодеков.

## Установка

Скачайте `Cord-Setup-0.7.4-x64.exe` или используйте постоянную ссылку
[Скачать Cord для Windows](https://github.com/MikkiMays/ModernStreamingSystem.Windows/releases/latest/download/Cord-Setup-x64.exe).
Установка выполняется для текущего пользователя без прав администратора; сохранённые
серверы и настройки сохраняются. Требуется Windows x64, начиная с Windows 10 build 19041.
