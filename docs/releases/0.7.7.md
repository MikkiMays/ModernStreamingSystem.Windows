# Cord 0.7.7

## Обновление ставится само

При запуске Cord первым делом проверяет, нет ли новой версии. Если есть — сразу появляется экран
«Обновление Cord…»: новая версия скачивается, проверяется, ставится и приложение открывается снова.
Нажимать «Обновить» и ждать уведомлений больше не нужно.

Если сервер обновлений недоступен, Cord через несколько секунд открывается как обычно и проверит
позже. Если загрузка или установка не удалась, экран называет причину и предлагает «Повторить» или
«Продолжить в этой версии». Встречу обновление не прерывает: найденная во время разговора версия
ставится, когда встреча закончится, или при следующем запуске.

## Версия — только в «О программе»

Номер версии больше не показывается в боковой панели и в сообщениях об обновлении. Узнать его можно
в настройках, в разделе «О программе».

## Установка

Скачайте установщик со страницы `/download` и запустите поверх установленной версии. Установка
выполняется для текущего пользователя без прав администратора; серверы, избранное и настройки
сохраняются. Требуется Windows x64, начиная с Windows 10 build 19041.
