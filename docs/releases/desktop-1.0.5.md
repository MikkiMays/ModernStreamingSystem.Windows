# Cord 1.0.5

## Выбор сервера: Франкфурт и Москва

В «Настройки → Подключение → Сменить сервер» теперь два сервера Cord — Германия, Франкфурт и Россия,
Москва. Переключиться можно в любой момент; выбор запоминается.

При первом запуске Cord открывает тот сервер, с которого скачан установщик. Если в настройках остался
сервер, которого больше нет в списке (например, от прежней установки), Cord не держится за него, а
переходит на свой сервер.

## Установка

Если Cord уже стоит, обновление придёт само при запуске. Иначе — скачайте установщик со страницы
`/download`.
