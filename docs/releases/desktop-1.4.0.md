# Cord 1.4.0

Cord переехал на новый адрес — `cord.online`. Это приложение открывается сразу на нём.

## Что изменилось

- Сервер Cord и обновления приложения — `cord.online`. Прежний адрес `cordcam.ru` больше не работает.
- Приложения прежних версий сами на новый адрес не перейдут: скачайте установщик с
  [cord.online/download](https://cord.online/download) и поставьте поверх. Настройки приложения сохранятся;
  избранное и недавние встречи на новом адресе начинаются заново.
