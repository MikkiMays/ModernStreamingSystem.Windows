# Cord 1.0.10

## Окно

- Шапка встречи снова прежнего размера, а кнопки окна «— ☐ ×» той же высоты: звезда, ссылка и
  «Поддержка» стоят с ними на одной линии и никогда не ложатся под них — ни в обычном, ни в
  развёрнутом окне.

## Установка

Если Cord уже стоит, обновление придёт само при запуске. Иначе — скачайте установщик со страницы
`/download`.
