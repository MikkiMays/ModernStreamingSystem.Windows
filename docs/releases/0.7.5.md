# Cord 0.7.5

## Обновление, которое действительно ставится

Кнопка «Обновить» скачивала новую версию, приложение перезапускалось — и снова показывало
прежнюю. Причина отказа при этом стиралась: следующий запуск говорил только «не удалось,
повторите» в плашке «Соединение», и повторить можно было ровно тем же путём.

Теперь помощник обновления:

- закрывает другие окна Cord, запущенные из папки установки, и завершает процесс Cord,
  который закрыл окно, но не вышел, — их открытые файлы и мешали установщику;
- повторяет установку один раз, если файл на секунду оказался занят (например, антивирусом);
- сверяет версию файла на диске после установки, а не верит коду выхода установщика;
- записывает каждый шаг в `update.log` в папке профиля.

После перезапуска приложение говорит, чем кончилось обновление, отдельной плашкой
«Обновление»: «Cord обновлён до версии 0.7.5» — или причину словами и путь к журналу.

**Важно для тех, у кого обновление не ставилось.** Переход на 0.7.5 выполняет ещё прежний
помощник. Если «Обновить» снова вернёт старую версию, установите 0.7.5 один раз вручную —
со страницы `/download` вашего сервера или по ссылке ниже, поверх установленной. Настройки,
серверы и избранное сохраняются. Дальше обновления идут уже новым помощником.

## Встреча

Изменения интерфейса встречи приходят с сервера: покерный стол снова занимает сцену
целиком, своя рука стоит сразу под столом, камера меняет качество без моргания, а меню и
настройки снова видны в полноэкранном режиме.

## Установка

Скачайте `Cord-Setup-0.7.5-x64.exe` или используйте постоянную ссылку
[Скачать Cord для Windows](https://github.com/MikkiMays/ModernStreamingSystem.Windows/releases/latest/download/Cord-Setup-x64.exe).
Установка выполняется для текущего пользователя без прав администратора; сохранённые
серверы и настройки сохраняются. Требуется Windows x64, начиная с Windows 10 build 19041.
