# Cord 0.2.1 для Windows

Первый опубликованный выпуск Windows-клиента для [ModernStreamingSystem](https://github.com/MikkiMays/ModernStreamingSystem). WinUI 3, .NET 10 и постоянный WebView2 подключаются к общему ядру и веб-клиенту.

## Скачать

- **Cord-Setup-0.2.1-x64.exe** — установщик со всеми библиотеками и полным автономным пакетом WebView2, 309 МиБ. Установка для текущего пользователя, ярлыки, обновление и удаление.
- **Cord-win-x64.zip** — переносимая сборка, 90 МиБ. Распаковать полностью; нужен установленный WebView2 Runtime.
- Файлы **.sha256** — контрольные суммы для проверки загрузки.

Минимум Windows 10 x64 build 19041; предпочтительно Windows 11. В настройках приложения укажите HTTPS-адрес развёрнутого веб-приложения. Адрес по умолчанию `http://localhost:5173` рассчитан на локальную разработку; сервер не устанавливается вместе с Cord.

## Возможности

Компактная главная, вход по коду/ссылке, до пяти избранных комнат, нативная боковая панель, системная тема и сохранение профиля. Общий веб-клиент поддерживает аудио, камеру, две демонстрации, чат и временные файлы. Уведомления Windows о смене сети передаются в общий механизм восстановления.

В публикацию явно включены ресурсы PRI/XBF. Проверка запуска загружает настоящий MainWindow и обнаруживает отсутствие ресурсов до распространения сборки.

## Проверка и ограничения

Локально пройдены 16 C#-тестов, публикация, установка, повторная установка и удаление. Общий клиент: 24 Vitest-теста и 9 браузерных сценариев с настоящим SFU и синтетическими источниками.

Установщик пока без собственной цифровой подписи; первоначальная установка WebView2 на чистой VM требует отдельной проверки. Реальные VPN-переходы, межустройственные задержки, аппаратные 1440p60 и производственный TURN/TLS не объявляются подтверждёнными. Медиатранспорт текущей версии — LiveKit SFU; прямой LAN/Bluetooth не реализован. [Полная инструкция и границы проверки](https://github.com/MikkiMays/ModernStreamingSystem.Windows/blob/main/docs/installer.md).
