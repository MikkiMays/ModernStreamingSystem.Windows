# Cord 1.1.6

Камера не должна отваливаться: она сама возвращается после сбоя, а камера и кодек больше не переключаются посреди
разговора. Почти всё это приходит с сервера Cord; номер приложения выровнен с сервером (одна версия продукта).

## Камера (с сервера)

- Если камера отвалилась или перестала отдавать кадры, Cord сам подключает её заново — включать вручную не нужно. Пока идёт
  восстановление, на своей плитке написано «Камера переподключается…».
- Кодек выбирается при включении камеры и посреди разговора не меняется, поэтому видео не пропадает у собеседников.
- Сообщений «компьютер не успевает» больше нет.

## В приложении для Windows

- Высокий приоритет получают ещё служба захвата камеры, видеокарта и сеть: на загруженном компьютере камера не должна
  оставаться без процессора первой.
