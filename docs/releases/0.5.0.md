# Cord 0.5.0

## Несколько серверов

Cord больше не привязан к одному адресу. В настройках появился **список серверов**: свой,
рабочий, друга — сколько нужно, с произвольными подписями и переключением в том же окне.

Записи хранятся по origin, поэтому два написания одного адреса не разъедутся в два профиля.
У каждого сервера свои имя, избранное, устройства и выданные разрешения — при переключении
они не смешиваются. Ранее сохранённый одиночный адрес переносится в список автоматически.

Обновления приложения приходят с одного фиксированного адреса и **не** следуют за выбранным
сервером: вход в чужую комнату не должен решать, какой файл установится на ваш компьютер.

## Исправлено

- **PING на главном экране.** Приложение и страница хранят настройки отдельно, а при старте
  передавались только профиль и тема. Задержка и звуки уведомлений доезжали до страницы лишь
  после повторного открытия настроек, поэтому на свежем запуске галка выглядела нерабочей.
  Теперь обе настройки передаются при старте.

## Что изменилось на стороне сервера

Интерфейс встречи загружается с сервера, поэтому следующее приезжает без переустановки:
видео с телефона больше не обрезается под горизонтальную плитку, меню участника по правому
клику открывается под курсором, выбранное качество передаётся как выбрано и не понижается
автоматически, а «Авто» само поднимается до максимума, который выдерживает связь.

## Установка

Скачайте `Cord-Setup-0.5.0-x64.exe` и запустите. Установка для текущего пользователя, без прав
администратора. Сохранённые серверы, имя и настройки переносятся. Windows x64, минимум
Windows 10 build 19041. Установщик пока не подписан сертификатом издателя.
