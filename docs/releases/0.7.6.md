# Cord 0.7.6

## Ровная марка в шапке

Вместо надписи «cord» с точкой в левом верхнем углу — нарисованная марка Cord: три полосы и слово.
Она стоит ровно по центру кнопки боковой панели и одинаково чёткая на любом масштабе экрана.

## Правая кнопка — без меню браузера

По правой кнопке больше не появляются «Проверить», «Сохранить как» и «Поиск в Bing». В поле ввода
остаются «Вырезать», «Копировать», «Вставить» и «Выделить всё», на выделенном тексте — «Копировать»,
в остальных местах меню не открывается.

## Ярлык на рабочем столе

В установщике галочка «Создать ярлык на рабочем столе» теперь включена сразу. Если её снять, при
обновлениях выбор сохраняется.

## Обновления только с сервера Cord

Приложение проверяет и скачивает обновления только с сервера Cord. Из установщика и из карточки Cord
в «Установленных приложениях» Windows убраны внешние ссылки, а описание в мастере установки больше не
предлагает переходить по сторонним адресам.

## Установка

Скачайте `Cord-Setup-0.7.6-x64.exe` со страницы `/download` и запустите поверх установленной версии.
Установка выполняется для текущего пользователя без прав администратора; серверы, избранное и
настройки сохраняются. Требуется Windows x64, начиная с Windows 10 build 19041.
