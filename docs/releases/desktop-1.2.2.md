# Cord 1.2.2

Cord открывается сразу, без пустого окна загрузки, а заставка обновления не пропадает до самого запуска. Остальное
приходит с сервера Cord.

## Запуск и обновление

- Знак Cord на заставке теперь живой. Проценты видны, пока скачивается обновление; дальше — «Устанавливаем…» и
  «Запускаем Cord…» с той же анимацией, до самого окна Cord.
- Окно Cord появляется ровно тогда, когда интерфейс уже нарисован, — раньше заставка пропадала, а окно ещё секунды
  грузилось.
- На время установки обновления на месте заставки остаётся окно с той же анимацией; новый Cord сменяет его без пустой
  паузы.
- В узком окне (как планшет) окно снова можно двигать — за верхнюю полосу с меню.

## С сервера

- «Звук встречи» с клавиатуры переключается ровно один раз на нажатие. Сочетания по умолчанию — Ctrl+F7 (микрофон)
  и Ctrl+F8 (звук встречи).
- Показывать экран может один участник; у остальных кнопка недоступна и подсказывает, кто показывает.
