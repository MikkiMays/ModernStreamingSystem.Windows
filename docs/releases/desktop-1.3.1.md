# Cord 1.3.1

Cord, обновлённый с прежней версии, снова открывается сразу на `cordcam.ru`, а не на странице «нет связи».

## Запуск

- Если сервер, который Cord помнил с прошлой версии, больше не работает, Cord сам переходит на `cordcam.ru`,
  как только получит свежий список серверов, — без перезапуска и без выхода через трей. Звонок и экран перед входом
  в звонок при этом не прерываются.
- В установщике снова есть список серверов: Cord знает `cordcam.ru` с первого запуска, даже пока сеть ещё не
  поднялась.

## С сервера

- «Настройки → Сервер»: кнопка «Авто» — встреча идёт через ближайший свободный узел; список узлов — по нажатию.
- Встречи больше не упираются в предел числа: новая встреча создаётся на ближайшем узле с запасом, перегретый узел
  уступает соседнему. В одной встрече — до 30 человек.
- Доска, картинки и снимок встречи хранятся не дольше суток.
