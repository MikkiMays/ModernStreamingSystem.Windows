# Cord 1.0.0

## Новый клиент

Cord для Windows теперь — собственное приложение со своим движком, а не окно браузера Windows.
Выглядит и ведёт себя как приложение: своя шапка окна, своё меню по правой кнопке без пунктов
браузера, значок в трее, кнопки микрофона, камеры и «завершить» на миниатюре в панели задач,
значок «во встрече» поверх иконки, уведомления с действиями, список переходов «Новая встреча»
и закреплённые комнаты, запрет сна во время звонка.

## Заставка при запуске

Как и прежде: сначала маленькое окно «Проверяем обновления…», при новой версии — загрузка с
процентами и установка, потом Cord. Обновления приходят только с сервера Cord, небольшими кусками,
с проверкой подписи и контрольных сумм.

## Показ экрана

Экран или окно выбирается в окне Cord с миниатюрами; на Windows можно показать вместе со звуком
системы. Сочетание микрофона работает поверх других программ.

## Серверы

Сервер выбирается из списка Cord — с флагом страны и пингом. Ручного ввода адреса нет.

## Установка

Скачайте установщик со страницы `/download`. Установка выполняется для текущего пользователя без
прав администратора; ярлык на рабочем столе создаётся по умолчанию. Прежнюю версию Cord удалите
через «Установленные приложения» — избранное хранится на сервере и останется. Требуется Windows
x64, начиная с Windows 10 build 19041.
