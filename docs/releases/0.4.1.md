# Cord 0.4.1

Исправлена доставка обновлений из приватного GitHub-репозитория. Приложение получает проверенные установщики через HTTPS-зеркало Cord; GitHub-аккаунт и токены в приложении не нужны. Проверяются источник релиза, версия, архитектура, размер и SHA-256.

Включены все изменения 0.4.0: обновление после встречи, полноэкранный режим, настройки избранного, PING и уведомлений, просмотр одного стрима с сохранением голоса.

Для перехода с 0.3.0 или 0.4.0 один раз запустите установщик 0.4.1. После этого новые опубликованные на зеркале версии доступны внутри приложения. Portable ZIP распространяется отдельно.
