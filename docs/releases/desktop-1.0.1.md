# Cord 1.0.1

## Показ экрана — своё окно выбора

«Показать экран» открывает окно Cord с вкладками «Экраны» и «Окна»: миниатюры, значки приложений,
двойное нажатие — показать. «Со звуком системы» — переключатель там же; участники услышат и звук
встречи, Cord предупредит об этом.

## Раздел «Windows» в настройках

Трей, кнопки на миниатюре в панели задач, значок поверх иконки, мигание, запрет сна во время звонка,
оверлей поверх игр со своим сочетанием клавиш и запуск вместе с Windows — каждый пункт включается
и выключается отдельно.

## Серверы

Список серверов обновляется сам и проверяется подписью; пинг до серверов снова виден.

## Установщик на восьми языках

Мастер установки говорит на языке Windows: русский, английский, испанский, французский, итальянский,
китайский, немецкий и португальский.

## Установка

Если Cord уже стоит, обновление придёт само при запуске. Иначе — скачайте установщик со страницы
`/download`.
