# Cord 0.6.1

## Windows теперь называет программу по имени

Установщик получил заполненный version-ресурс: название, версию, описание и издателя. Их
читает Windows, когда описывает файл, — в свойствах файла и в том самом окне SmartScreen для
неподписанной сборки.

Предупреждение это **не убирает**: изнутри файла его не убрать ничем. Оно решает, назовёт ли то
окно программу или покажет пустое место. Что именно убирает предупреждение и кому это доступно
— [installer.md](../installer.md#предупреждение-smartscreen-и-подпись).

## Сборка готова к подписи

`scripts/sign.ps1` подписывает `Cord.exe` до упаковки ZIP и Setup до подсчёта SHA-256. Без
сертификата он пишет строку в лог и ничего не делает — сборка ведёт себя ровно как раньше.
Включение подписи после появления сертификата стоит двух секретов и ни одной правки кода.

## Установка

Скачайте `Cord-Setup-0.6.1-x64.exe` и запустите. Установка для текущего пользователя, без прав
администратора. Сохранённые серверы, имя и настройки переносятся. Windows x64, минимум
Windows 10 build 19041.
