# Cord 0.4.0

В установленной Windows x64-версии появилась строка версии и загрузка новых стабильных выпусков внутри приложения. Пакет проверяется по SHA-256, устанавливается после встречи без мастера, после чего Cord запускается снова. Каталог установки, профиль, избранное и настройки сохраняются.

Веб-клиент поддерживает отдельный просмотр одного стрима, выборочные подписки на экран и его звук, закрепление камеры, полноэкранный разговор и меню участника. Нативное избранное получило отдельную кнопку настроек, включая недоступные комнаты. Добавлены настройки PING и звуков уведомлений.

Для перехода с 0.3.0 нужно один раз запустить новый установщик: загрузчика обновлений в 0.3.0 нет. Portable ZIP по-прежнему обновляется отдельно.
