# Cord 1.2.3

Cord теперь живёт по одному адресу — `cordcam.ru`: новые установки и обновления идут оттуда.

## Сервер

- Сервер по умолчанию — `cordcam.ru`, оттуда же приходят обновления клиента.
- Каталог серверов продукта — один адрес; прежний стенд из него убран.
- Если сервер встречи перестал отвечать, встреча переезжает на другой быстрее — около 6–8 секунд до звука вместо
  прежних 15 (с сервера).

## С сервера

- Микрофон после долгой встречи включается так же быстро, как в начале: у собеседников больше не растёт задержка звука
  от каждого выключения.
- Громкость музыки и кинозала можно менять и выключать и с телефона.
