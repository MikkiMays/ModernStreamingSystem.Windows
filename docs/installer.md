# Установка и распространение Cord

Клиент Windows — Electron (ADR 0001). Для установки нужен один файл **`Cord-Setup-<версия>.exe`** — установщик
NSIS из electron-builder с приложением, его Chromium и нативным модулем `cord-native` внутри. Ни WebView2, ни
.NET, ни чего-либо ещё ставить не требуется.

Номер версии здесь намеренно не указан: берите файл со страницы `/download` **того сервера, которым пользуетесь**
(она ведёт на последний установщик, показывает размер и отдаёт файл с того же домена), или из последнего выпуска
`desktop-v<версия>` на GitHub. Номер версии приложение показывает только в «О программе» (T58).

## Установка

Как у Телемоста — одно маленькое окно с полосой, без страниц мастера (R105), но с выбором языка (R64): два нажатия.

1. Передайте установщик на компьютер с Windows x64. Минимум — Windows 10 build 19041; предпочтительно Windows 11.
2. Запустите его. Откроется окно выбора языка — восемь языков Cord (русский, English, Español, Français,
   Italiano, 简体中文, Deutsch, Português do Brasil); выбор запоминается (`HKCU\Software\Cord\InstallerLanguage`)
   и на этом же языке откроется Cord при первом запуске. Дальше язык меняется в настройках Cord.
3. «OK» — и дальше только окно с полосой («Установка, пожалуйста, подождите…» на выбранном языке). Cord
   ставится для текущего пользователя в `%LOCALAPPDATA%\Programs\Cord` **без прав администратора**
   (`requestedExecutionLevel: asInvoker`, `perMachine: false`) и открывается сам. Папка не выбирается.
4. Ярлыки — в меню «Пуск» и на рабочем столе, всегда (убрать — как любой ярлык). У обоих AppUserModelID
   `tech.cord.desktop` (тот же, что объявляет процесс): так Windows показывает уведомления Cord и группирует его окна.
5. Сервер для первого запуска берётся из подписанного каталога, который едет с установщиком
   (`src/shell/catalog.jws`), дальше — из сети; сменить сервер можно в настройках.

Регистрируется схема `cord://` для текущего пользователя (`HKCU\Software\Classes\cord`): ссылки `cord://room/<код>`
открывают встречу в установленном Cord.

## Что проверяется в CI

Каждый прогон `desktop.yml` на `windows-2022` после упаковки запускает `desktop/scripts/test-installer.ps1`:
тихая установка `/S` — время печатается и попадает в `metrics.json` (`installSeconds`, порог R105 — 20 с,
превышение — предупреждение), папка именно `Programs\Cord`, карточка «Установленные приложения» без единой
ссылки и с издателем «Cord», ярлыки на рабочем столе и в «Пуск» с верным AUMID, язык установщика в HKCU, схема
`cord://`, запуск установленного Cord (заставка, cord-native в utility-процессе), крестик прячет окно в трей,
метрики холодного старта и памяти (`metrics.json`, ADR §10), тихое удаление. С `-Screenshots release` — ещё и
обычный запуск, как у человека: снимок окна выбора языка, программное «OK», снимок окна с полосой, время
установки; снимки `installer-*.png` — в артефакте прогона. С `-Previous previous` — обновление поверх настоящего
`Cord-Setup-1.0.5.exe` из релиза `desktop-v1.0.5` (sha256 сверяется): 1.0.5 ставится тихо (ярлык по своей галочке,
`DesktopShortcut = 1`; выбор языка человеком — `InstallerLanguage = Language = 1031`, не язык Windows), поверх —
эта сборка так, как её запускает electron-updater (`--updated /S --force-run`); проверяются та же и единственная
папка `Programs\Cord`, ярлыки рабочего стола и «Пуск» с AUMID, сохранённый язык, убранный `DesktopShortcut`,
схема `cord://`, на диске `app.asar` этой сборки, запуск Cord, одна запись удаления; итог — `metrics.json` → `update`,
любая неудача — красный прогон. Вид на 125–200 % и на живой машине — вручную.

## Как устроен установщик

- `desktop/electron-builder.yml` — цель `nsis`: `oneClick: true` (окно с полосой — SpiderBanner, значок —
  `installerHeaderIcon`), `perMachine: false`, `createDesktopShortcut: true`, `createStartMenuShortcut: true`,
  `runAfterFinish: true`, восемь `installerLanguages`, без ссылок и `homepage`.
- `desktop/build/installer.nsh` — окно выбора языка (`MUI_LANGDLL_DISPLAY` в `customInit`, не в тихом режиме;
  `displayLanguageSelector` выключен, потому что electron-builder вставил бы его и в тихий режим);
  `ManifestDPIAware`; папка свежей установки — `Programs\Cord` (в режиме «одним окном» electron-builder назвал бы
  её по имени пакета, `cord-desktop`; обновление ставится туда, где стоит); запись языка, описания в карточке
  (`Comments`, `LangString` на восемь языков), схемы `cord://`, чистка карточки Windows.
- Надпись над полосой и вопрос деинсталлятора «Удалить Cord?» — стандартные тексты electron-builder на языке мастера.
- `desktop/build/installerSidebar.bmp` и `installerHeader.bmp` установщику «одним окном» не нужны; остались для
  мастера, если он вернётся (`npm run icons`, `scripts/make-icons.mjs`).

**Переход с 1.0.5 и раньше.** Там ярлык на рабочем столе ставила своя галочка (`HKCU\Software\Cord\DesktopShortcut`),
а прежний деинсталлятор, который запускается при обновлении, этот ярлык удаляет. 1.0.6 возвращает его один раз,
если галочка стояла, убирает старое значение, и дальше ярлыками ведает electron-builder: при обновлении он их не
трогает, при удалении — удаляет.

## Предупреждение SmartScreen и подпись

Пока EXE не подписан сертификатом издателя, Windows показывает «Система Windows защитила ваш компьютер» и называет
издателя неизвестным. **Убрать это изнутри установщика нельзя**; права администратора не помогают — установка и так
идёт без повышения прав. Решает только подпись Authenticode сертификатом, которому Windows доверяет:

| Вариант | Что даёт |
| --- | --- |
| Без сертификата (сейчас) | Предупреждение на каждой новой версии; репутация копится по хешу файла и обнуляется с каждой сборкой |
| OV-сертификат | Издатель назван; репутация копится по сертификату и переживает новые версии, но первые загрузки всё ещё предупреждают |
| EV-сертификат или [Microsoft Artifact Signing](https://learn.microsoft.com/en-us/azure/artifact-signing/overview) | Предупреждения нет практически сразу |

Про Artifact Signing стоит знать заранее, кому он доступен: по [инструкции Microsoft](https://learn.microsoft.com/en-us/azure/artifact-signing/quickstart)
сертификаты Public Trust выдаются организациям из США, Канады, ЕС, Великобритании, Австралии, Новой Зеландии, Японии,
Южной Кореи, Сингапура, Швейцарии, Норвегии и Израиля, а **индивидуальным разработчикам — только из США и Канады**.
Цена Basic — $9.99 в месяц за 5 000 подписей (на 15.09.2026); проверка личности — от 1 до 20 рабочих дней.

Сборка к подписи готова: CI подписывает `Cord.exe` и установщик, если заданы секреты `CORD_SIGN_PFX_BASE64`
(файл `.pfx` в base64) и `CORD_SIGN_PASSWORD` (`CSC_LINK`/`CSC_KEY_PASSWORD` electron-builder); без них сборка
неподписанная и ведёт себя как сейчас. Метка времени RFC 3161 обязательна: без неё подписи перестают проверяться в
день истечения сертификата — и у тех, кто уже установил Cord.

Если Microsoft Defender пометит файл ошибочно, это **не** SmartScreen и лечится
[заявкой на анализ файла](https://www.microsoft.com/en-us/wdsi/filesubmission) — бесплатно.

## Обновление и удаление

Cord проверяет обновления сам: при запуске — на заставке, до главного окна, и далее раз в шесть часов. Новую версию
он ставит сразу, не спрашивая (во время встречи — после её конца): установщик запускается тихо (`/S --updated`),
окно выбора языка при этом не показывается, прежние язык, папка и ярлыки сохраняются.
Проверяются версия, адрес, размер и SHA-256 пакета, манифест `latest.yml` подписан Ed25519; подробности в
[updating.md](updating.md). Канал обновлений фиксирован и **не** зависит от того, к какому серверу вы подключены.

Установить новую версию можно и вручную, поверх существующей: постоянный `appId` сохраняет установочную запись и
каталог. Перед обновлением завершите звонок.

Удаление — Windows → «Параметры» → «Приложения» → Cord → «Удалить Cord?» → «OK». Удаляются установленные файлы и ярлыки; `%LOCALAPPDATA%\Cord`
с настройками и профилями остаётся (`deleteAppDataOnUninstall: false`): повторная установка под тем же пользователем
найдёт сохранённые имя, сервер и профиль избранного.

## Сборка

```powershell
cd desktop
npm ci
npm run build:native   # cord-native (Rust, только Windows)
npm run build          # main, preload, страницы оболочки + проверка состава dist
npx electron-builder --win nsis --x64 --publish never   # release\Cord-Setup-<версия>.exe
.\scripts\test-installer.ps1 -Release release           # тихая установка, проверки, удаление
.\scripts\test-installer.ps1 -Release release -Screenshots release   # и обычный запуск со снимками
```

`test-installer.ps1` ставит Cord в настоящий `%LOCALAPPDATA%\Programs\Cord` и удаляет его в конце — на машине, где
Cord уже стоит, запускать не стоит.
