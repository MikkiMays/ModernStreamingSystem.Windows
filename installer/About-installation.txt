Cord для Windows

Установщик содержит приложение, библиотеки .NET, Windows App SDK и ресурсы интерфейса. Если Microsoft Edge WebView2 Runtime ещё не установлен, он будет установлен из включённого автономного пакета Microsoft. Для распаковки этих компонентов интернет не требуется.

Cord устанавливается для текущего пользователя в папку AppData\Local\Programs\Cord. Он появится в меню «Пуск» и в списке установленных приложений Windows. Ярлык на рабочем столе можно включить отдельно.

Для звонков нужен доступ к интернету. Новая установка автоматически подключается к https://meet.nikg.tech — этот же адрес можно открыть в браузере. Запускать сервер на своём компьютере или вручную настраивать адрес не требуется. При обновлении ранее сохранённый адрес сервера сохраняется; его можно изменить в настройках Cord.

При обновлении сохраняются имя, избранное, адрес сервера и настройки устройств. Перед обновлением завершите звонок и закройте Cord. Удаление приложения сохраняет пользовательский профиль и общий WebView2 Runtime.

Распространение WebView2 — https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution
